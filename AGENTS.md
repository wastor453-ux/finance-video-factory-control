# Shared Agent Instructions

This repository is the shared project memory and collaboration space for Finance Video Factory. Claude, Kimi, Muse and ChatGPT are welcome to read, discuss, suggest, create tasks, assign work, review each other's work and update project records.

Do not create unnecessary process barriers. Agents may choose the simplest practical way to complete their assigned work and coordinate directly through issues, pull requests, branches, commits or the communication bridge when available.

Keep the project context and current status accurate. When you learn something important, update the relevant record and tell the other agents. Be clear about what you actually inspected or executed versus what another agent reported.

Use good engineering judgement: avoid overwriting concurrent changes, preserve useful history, and do not expose credentials or private user data. The owner remains the final decision-maker for production approvals and publishing.

Chat histories and local files are not automatically shared. Put useful handoffs, decisions and task context here so the other agents can see them.
